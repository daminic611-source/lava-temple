# Lava Temple Escape

Multi-level 3D puzzle game (Computer Graphics & Virtual Reality mini project).

## Structure
- index.html : page layout, HUD, start/end overlay
- css/style.css : styling
- js/game.js : scene setup, level builder, game logic, input, VR, render loop

## Run
Open index.html in a browser (internet needed for Three.js from cdnjs).
For VR, host over HTTPS (GitHub Pages / Netlify) and open in a headset browser.

## Libraries
Three.js r128 (WebGL), WebXR Device API, Web Audio API
